# C3 · Post-blast digital reconstruction lab

<div class="module-card">

**Prerequisites** Stages 4 and 8, P01, P09, P10. **Estimated time** 60–90 h. **Level** Advanced–Expert.

</div>

## Problem

Build a reconstruction pipeline for **synthetic** post-blast scenes (abstract yield units, generic
urban geometry) that infers the event's seat location and abstract yield — with calibrated
uncertainty — from heterogeneous evidence, and produces a court-style technical report.

## Pipeline

1. **Scene synthesis** (extend P10 + P01): a fictional plaza with buildings, glazing, street
   furniture; a hidden event (seat, abstract yield, height); evidence generated by physics:
   window breakage (threshold distribution × incident/reflected/shielded load), displaced objects
   (dynamic-pressure driven, noisy directions), fragment deposition (radial throw truncated by
   obstacles), photographs (rendered views with known camera poses).
2. **3D capture**: structure-from-motion on the rendered photographs (OpenCV) → sparse point cloud
   → scale from a known reference → registration to the site plan.
3. **Evidence triage with CV**: detect evidence items in the images (P09), de-duplicate across
   views, geolocate by triangulation.
4. **Inference**: Bayesian model p(seat, W | evidence) with explicit likelihoods for each evidence
   type; MCMC (random-walk Metropolis or HMC) → posterior; posterior predictive checks.
5. **Report**: seat credible region, yield credible interval (note the R³ amplification), sensitivity
   analysis to model assumptions (threshold distribution, surface factor, shielding model),
   chain-of-custody log for every evidence item used.

## Requirements

| Id | Requirement |
|---|---|
| R1 | 90 % credible regions achieve ≥ 85 % empirical coverage over 50 synthetic scenes |
| R2 | Seat median error ≤ 3 m in the Intermediate scene family |
| R3 | Every inference input traceable to an evidence record with provenance |
| R4 | Sensitivity analysis quantifies which assumption dominates the yield uncertainty |
| R5 | Report readable by a non-specialist; limitations stated explicitly (Daubert-style error rates, 08.3) |
